A two-player online co-op mod for **Hitman: Blood Money**.

## How to play

This mod only supports the latest retail version of the game on either [Steam](https://store.steampowered.com/app/6860/Hitman_Blood_Money/) or [GOG](https://www.gog.com/en/game/hitman_blood_money).

1. Download the mod installer from [the latest release](https://github.com/OrfeasZ/hbm-coop/releases).
2. Run the installer and select the folder where your game is installed.
3. Run the game as usual and select **CO-OP** from the main menu.
4. Select a co-op profile to use or create a new one. You can also copy an existing single-player profile to keep your unlocks. Co-op progress is separate from single-player progress.
5. If you want to host a game, select **HOST A GAME**, enter the relevant details so your friend can find it, and then select **CREATE LOBBY**.
6. If you're joining a game, simply select the lobby to join it.
7. Once both players are in, select **START GAME** to enter the hideout.
8. From the hideout, the host can start a mission from the laptop near the entrance.

## Additional enhancements

This mod includes several additional enhancements to the core game, including:

- Borderless windowed mode, an expanded resolution list, and monitor selection.
- Adjustable third-person field of view, from 60 to 120 degrees.
- Automatic menu and interface scaling based on resolution, with a manual scale setting.
- High resolution text in menus and the HUD.
- Native mouse cursor in menus, improved mouse capture and focus handling.
- The game continues running when its window loses focus.
- Framerate is capped to 60fps to prevent glitches.

You can find new settings in the game's options menu. Changing between exclusive fullscreen and other display modes requires restarting the game.

## New controls

| Key | Action |
| --- | --- |
| Hold **Tab** | Shows your partner's view in picture-in-picture and outlines them through obstacles. |
| Hold **H** | Opens the emote wheel. |
| **Alt+Enter** | Switch between windowed and borderless modes. |

Other controls use your existing game bindings. You can change the **PARTNER VIEW** and **EMOTE WHEEL** PiP bind from the co-op options menu.

## Current limitations and gameplay changes

- *Death of a Showman* and *Requiem* are currently not available in co-op.
- Only the original partner can rejoin an ongoing mission.
- Some single-player functionality may be broken while the mod is installed.
- Random projectile spread is disabled in co-op.
- No manual mission save/load during co-op.
- Menus and inventory do not pause co-op gameplay.

This mod has been tested relatively thoroughly and *most* things should work as expected. However, there's almost definitely going to be some things that do not. Please report any issues you encounter [here](https://github.com/OrfeasZ/hbm-coop/issues). If your game crashes, you will find an `hbm-coop-XXXX.log` file in your game folder with crash details. Please make sure to include that in any issues you open, along with information of what you were doing before the crash!
